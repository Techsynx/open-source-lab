# Open Source Lab

> Open-source algorithms, system utilities, and agentic workflows maintained by [Techsynx](https://github.com/Techsynx).

## Modules

- `core`: Fundamental data structures and algorithmic utilities
- `sysutils`: System monitoring and process utilities
- `agentic`: Context management and orchestration helpers
- `security`: Safe sanitization and secret masking utilities
- `benchmarks`: Performance evaluation and latency tracking
